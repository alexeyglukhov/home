# Счётчики воды (БелЦЕННЕР)

Квартира: Копище, ул. Николая Камова, д. 11, кв. 26. Четыре счётчика: 2 холодных + 2 горячих.

## Что на фото — три разных номера

| Что видно | Это | Для оплаты |
|---|---|---|
| Короткий **6 цифр** (`436967` и т.п.) | Заводской № счётчика | Да — поля «Сч-к N…» |
| Длинный `04B64819…` / штрихкод | № радиомодуля LoRa | Нет |
| Круглая наклейка/голограмма | Пломба поверки | Нет |

Заводской № ищи на латунном корпусе сбоку/снизу или мелким шрифтом на циферблате — **не** на LoRa-наклейке.

## Холодная / горячая

- Синее кольцо, `ETK… T30` → **холодная**
- Красное кольцо, `ETW… T90` → **горячая**

В форме оплаты:

| Поле | Тип | Заводской № |
|---|---|---|
| Счётчик 1 | холодная | 436967 |
| Счётчик 2 | холодная | 436968 |
| Счётчик 3 | горячая | 437687 |
| Счётчик 4 | горячая | 437688 |

Пока заводской № не прочитан: синие → только поля 1–2, красные → только 3–4. Внутри пары (1↔2, 3↔4) можно менять местами, если предыдущие одинаковые.

## Как читать показание

1. Чёрные ролики — целые м³, красные — доли.
2. Не сдвигать запятую «на глаз» по длинному LoRa-номеру.
3. Если сомнение (блик, обрезан кадр) — спросить пользователя, а не угадывать.
4. Типичная ошибка модели: принять `000085` за `8,5` вместо `0,85`, `000162` за `16,2` вместо `1,62`, `000139` за `13,9` вместо `0,139`. Ориентир — красная зона = дробная часть; ведущие нули слева от запятой.

Пример сверки с пользователем (окт 2026):

| Цвет | Показание |
|---|---|
| синий | 0,85 и 1,62 |
| красный | 0,139 и 0,322 |

## Ответ для подачи

Коротко, как поля формы:

```
Счётчик 1 (холодная) — …
Счётчик 2 (холодная) — …
Счётчик 3 (горячая) — …
Счётчик 4 (горячая) — …
```

Если текущее меньше «предыдущ. знач.» на форме — предупредить: система может не принять.

## Известные LoRa (ориентир пар, не для ЕРИП)

Пары на фото (не привязаны жёстко к Сч-к 1–4 без заводского №):

- синий `…8443` / красный рядом
- синий / красный `…8830` и соседний синий
