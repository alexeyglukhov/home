# Топочная V3: подписи и коммуникации

Источник правды по пятнам оборудования: файл `house-light/topochnaya/plan-v3.svg` (сборка скриптом `build-plan-v3.py`). Код сцены: файл `house-light/topochnaya-v3.js`. Коммуникации при каждой перерисовке 3D прокладывать заново по правилам ниже; на плане труб нет.

Комната: **3,50 × 1,98 × 2,70 м**. Оси: X запад→восток, Z север→юг, Y вверх. Центр пола (0,0,0). Стена 0,15 м. Выводы за стену: **+10 см** за наружную грань.

## Порядок работы

1. Правки расстановки - на `plan-v3.svg` (пятно, синяя полоса = стена, красная стрелка = фронт).
2. Перенести пятна в функцию `layoutPorts()` / `buildEquipment()`.
3. Переложить трубы в функцию `buildPipes()` по правилам коммуникаций.
4. Расставить подписи по правилам подписей.
5. Собрать план: `python3 house-light/topochnaya/build-plan-v3.py`.
6. Рендер: `python3 house-light/topochnaya/render-views.py`. Кэш: `topochnaya-v3.js?v=` в `app.js`, `app.js?v=` в `index.html`, `_reinit=` в `render-views.py`.

## Оборудование: РБ и группы безопасности

- Расширительных баков **ровно два**:
  - **РБ-СО** - контур отопления;
  - **РБ-котлы** - общий на котлы / связанный контур (не отдельный бак на каждый котёл).
- На каждом котле (ГАЗ, ЭЛ, ТТ) - **группа безопасности** (ГБ): предохранительный клапан, воздухоотводчик, манометр в одном узле у подачи. Это не РБ.
- В 3D не рисовать четыре бака РБ-Г / РБ-Э / РБ-СО / РБ-ТТ.

## Зафиксированная модель ТТ

**АОТВ «СТЭН mini-11»** (продажа в РБ: https://sten.by/katalog/kotlyi-tverdotoplivnyie/sten-mini/sten-mini-11-terrakot.html).

| Параметр | Значение | Источник |
|----------|----------|----------|
| Мощность | 11 кВт (уголь), до ~110 м² | паспорт СТЭН mini-7/11 |
| Габариты Д×Ш×В | **660×338×560 мм** | паспорт |
| Глубина с дымоходом (карточка) | 685 мм | sten.by |
| Рабочее давление | **1 атм** | паспорт |
| Дымоход | вертикальный вверх, Ø115 мм | паспорт |
| Подача СО | задняя стенка сверху (~500 мм от пола), G 1¼″ | паспорт |
| Обратка СО | бок слева или справа, низко (~113 мм), ~55 мм от тыла | паспорт |
| Паспорт PDF | https://www.stenbel.by/assets/docs/sten-mini-7-11-pasport-25-01-2024.pdf | |

Отступы по руководству СТЭН: зад/бок несгораемая **≥0,10 м**, горючая **≥0,15 м**, фронт (дверца) **≥1,25 м**.

Расстановка: **у восточной стены**, дверца на запад. Пятно **0,34 × 0,66 м**, `ttRotY = -π/2`, зад 0,10 м от востока. Подпись: «СТЭН mini-11».

Источник пятен: `plan-v3.svg` / `plan-v3-layout.json`.

## Патрубки котлов (рисовать только так)

### ГАЗ (настенный) и ЭЛ
- Гидравлика и газ - **снизу** корпуса. Спереди: слева **подача СО**, справа **обратка**.
- Коаксиал ГАЗ - с **верхней крышки** (`gasCoax`). Трасса: вверх → по потолку на юг → через южную стену **+10 см**. Горизонт ~2 м; у Ø60/100 обычно до 3-5 м по паспорту котла.
- ЭЛ коаксиала нет.

### ТТ СТЭН mini-11
- Фронт (дверца) - **только загрузка**, воды там нет.
- **Подача** - задняя стенка сверху; при ориентации на восток - на **тыле (+X)**.
- Труба подачи от тыла идёт **вдоль восточной стены** на север к магистрали СО; не выводить на фронт. У ТТ сразу поднять на высоту магистрали СО (`Y.so`), чтобы не протыкать Fe (Fe на той же восточной полосе севернее ТТ).
- **Обратка** - бок низко; в 3D - **северный** бок (−Z).
- Дымоход - верхняя панель, вверх.

### БКН
- ХВС - низ; ГВС - верх; змеевик СО - сбоку.

## Дымоход ТТ (как рисовать)

1. Патрубок Ø115 на **верхней панели** (чуть к тылу), не на дверце и не в водяных штуцерах.
2. Только ортогонально: от патрубка **вертикально вверх** через кровлю.
3. Не пересекать водяные патрубки; подпись «дымоход ТТ» у ствола.
4. Цвет `flue` серо-коричневый, Ø ≈ 0,115 м.

## Подписи

### Размещение

- Якорь = центр или поверхность объекта. `face` = сторона к центру комнаты (N/S/E/W).
- Зазор от поверхности: **7 см** (`front`). Если якорь в центре: `front = halfDepth + 0.07`.
- При наложении сначала Y, иначе вдоль стены. XZ у объекта не разъезжать.
- API: `wallTag`, `nodeTag`, `floorTag`.

### Содержание

- Подписывать: котлы, ГБ, БКН, СТЭН mini-11, ТТ подача/обратка, топливо, два РБ, насосы, гребёнка, смес, дверь, окно, лапамойка, Fe/Ф1/Ф2, автоматика, ИБП, АКБ, К1, приток, коаксиал, дымоход, ключевые трубы.
- Зоны фронта: настенные ≥1 м; ТТ **≥1,25 м**.

## Коммуникации

### Геометрия труб

- Только **ортогональные** сегменты. Манхэттен Y → X → Z.
- Магистрали: север `nRail = zN+0,10`, запад `wRail = xW+0,12`, юг `sRail = zS−0,18`.
- Полосы на полу без наложения (разные X).
- Вывод наружу: прямой штуцер **+10 см**, **без поворотов снаружи**. Внутри комнаты опуск → к стене → +10 см (`floorWallExit` / `wallOut*`).
- СО→смес: высоко у западной стены; не через фронт ЭЛ.
- Гребёнка и смес: `z ≤ −0,72`, разведены по высоте.
- Дренаж → **К1** между лапамойкой и Fe.
- Цвета: ХВС синий, ГВС красный, СО оранжевый, ТП бирюза, газ жёлтый, дренаж коричневый, санузлы фиолетовый, дымоход/коаксиал серо-коричневый.

### Оборудование и ориентация

| Объект | Стена | Фронт (в комнату) |
|--------|-------|-------------------|
| ГАЗ, ЭЛ, БКН, РБ-СО, РБ-котлы, Н-*, колл.СО, ГС, СВШ | север | юг (N) |
| СТЭН mini-11 (+ГБ), топливо | восток | запад (E) |
| гребёнка, смес, дверь, лапамойка | запад | восток (W) |

- Автоматика: щит на юге; высота панели ×1,7 вниз от прежнего верха.
- Лапамойка: полая чаша; ничего не прятать внутри чаши.
