# Карта мебели Д2

Редактируемая SVG-схема расстановки. **Карта — источник истины** для 3D:
поворот, зеркало и пропорции пятна (ширина×глубина). Высоту модели не меняем.

## Файлы

| Файл | Назначение |
|------|------------|
| `../furniture-map-d2.svg` | Карта — правите руками |
| `../furniture/previews/*.png` | Превью каталога (фасад к зрителю) |
| `build_map_d2.py` | Пересобрать карту из JS + подложка |
| `sync_map_to_place.py` | Записать правки из SVG в `furniture-place-d2.js` |
| `render_previews.mjs` | Сгенерировать PNG превью |
| `inject_catalog_palette.py` | Вставить палитру каталога на карту |

## Подложка и каталог

- `plan-underlay` — комнаты, стены, проёмы, эскиз мебели (`pointer-events:none`).
- `catalog-palette` (справа от дома) — **не синхронизируется**. У каждого объекта:
  - снимок: **фасад к зрителю**;
  - пятно со **стрелкой сзади→вперёд**, как на снимке;
  - натуральный размер пятна (см из каталога).

**Как взять модель:** в Inkscape скопируйте группу `catalog-ITEM` (только пятно со стрелкой, без скриншота рядом) и перетащите на план. Синк подхватит и копию с `catalog-item` (лучше сменить `class` → `furn` и вынести из слоя палитры, иначе пересборка каталога сотрёт объект).

Пересобрать превью + палитру:

```bash
cd house-light
node furniture-map/render_previews.mjs
python3 furniture-map/inject_catalog_palette.py
```

## Как править расстановку

1. Откройте `furniture-map-d2.svg` в Inkscape.
2. Группа `furn-*`: прямоугольник = пятно, красная стрелка = **перед** (фасад / сиденье / чаша / изножье).
3. Двигайте, масштабируйте, вращайте, зеркальте **группу целиком**.
4. `data-model` — ID из каталога.

## Синхронизация в 3D

```bash
cd house-light
python3 furniture-map/sync_map_to_place.py
# поднимите furniture-place-d2.js?v= в app.js и app.js?v= в index.html
```

Синк пишет `frontDeg`, `footW`×`footD`, `mirror`, `fromMap: true`.
В 3D: ориентация и XY по карте; **высота модели натуральная**.
